工具

策略验证 · 组合风控 · 持仓体检 · 断层率信号 · 查任意一件

这一页怎么用 先看这 1 分钟

这 4 个工具原本是电脑上跑的 Node 脚本。这里显示的，是它们跑出来的结果： 电脑上跑 → 导出 JSON → 这里只读展示，每天跟着流水线更新一次。 本页不发任何命令、不做在线执行；唯一的例外是下面「查任意一件」—— 那是把体检器算分的那段逻辑搬到了浏览器里，用你已经下载到手机上的日线当场算， 同样不联网、不执行任何命令。

① 电脑上跑 4 个脚本→② 导出 JSON→③ build_tools.cjs 聚合→④ 手机只读展示

这 4 个脚本分别是 strategy_lab.cjs（策略验证）· portfolio_risk.cjs（组合风控）· inspect.cjs（单品体检）· scan_washout.cjs（断层率信号）。

① 策略验证 样本外检验把每个「交易想法」拿去和随机日对照，能过的才留
怎么读看「样本外」和「对照」两列 —— 样本外 ≥ 对照才算有效。「样本内」好看但「样本外」差 = 过拟合，是巧合不是规律。
能帮你让你不再相信一个「听起来很有道理、实际没用」的信号。9 个想法里有几个已经被杀掉了，名单就在下面。
不能帮你不能预测价格。它只回答「这个规律在过去那段没被用来调参的时间里还成立吗」，不回答「明天涨不涨」。
② 组合风控 纯算术算你的集中度、历史波动，以及「减哪几件能降多少波动」
怎么读两个关键数字：volReductionPct（按方案减仓后，组合历史年化波动降多少）和枪族 HHI（是不是把同一个赌注重复下了很多遍）。
能帮你告诉你减仓的代价与收益：能回款多少现金、会实现多少亏损、波动降几个百分点。
不能帮你不预测涨跌。「降波动」和「降集中度」是两个不同目标 —— 页面给了两版方案，只能选一个当主目标，别混着看。
③ 持仓体检 逐件打分44 件一件一件打分（磨损 / 单价 / 断层率 / 退出天数 / 数据完整性）
怎么读看等级和分数：A 最该留、D 最该先处理。点开每一件能看到「这几分是怎么加出来的」，每一项都写了理由。
能帮你一眼看出 44 件里哪几件该先处理，不用自己一件件翻。
不能帮你分数只包含已验证的条件（磨损段位 / 单价下限 / 断层率 / 退出天数 / 数据完整性）。「趋势修正」那部分是机械规则（现价 vs MA90、30 天跌幅），属于启发式，没有做过样本外检验。
④ 断层率信号 唯一过检全项目唯一通过样本外检验的信号：断层率落在 12%~16%
怎么读看「倍数」列：现断层率 ÷ 它自己 365 天的中位数。倍数 ≥ 2 才算真异常（页面里标了「强信号」徽标）。
能帮你直接给你一批候选（当前快照里 — 个落在区间内，其中 — 个是强信号），省掉自己扫全池。
不能帮你它是概率优势，不是保证：样本外 prob30 只有 35.8%（对照 27.8%）。另外单价 < ¥1 的品，断层率是分位舍入出来的假振幅，不能当盘口证据。
三个数字提示（很重要，别踩坑） 1）看时间：每个区块都标了「结论时间」和「价格时间」——价格是 3 分钟级刷新，结论是日更，两者不同步是正常的。
2）已验证 / 未验证要分开看：页面里凡是写着「未验证 / 已证伪 / 不计分」的东西（铺货墙、吸筹合成分、计分模型信号、倍数那列），都不能和已验证的结论混着用。
3）本页不构成投资建议，也不预测价格；所有「target / 止损」都只写「历史上到过的位置」。

工具页是什么：这 4 个工具都是电脑上的 Node 命令行程序（strategy_lab.cjs / portfolio_risk.cjs / inspect.cjs / scan_washout.cjs）。GitHub Pages 是纯静态页、没有执行环境，所以流程是：电脑上跑工具 → 产出 JSON → 聚合器 build_tools.cjs 合成 tools.json → 这里只读展示。本页不发任何命令、不做在线执行；每个数字都标了口径与时间。 快照加载中…

查任意一件 按需加载

这是什么：「单品体检器」的手机版。输入中文名 / 英文名 / gid，选中后当场在浏览器里算完整体检—— 断层率（含 365 天中位 / p10 / p90）、价格变化（7/30/90/180 天）、在售与求购变化、 RSI / 布林带宽 / Z值 / 年化波动 / 最大回撤、评分与等级，以及这份数据缺了什么（dataGaps）。 算分公式与电脑端 inspect.cjs 完全等价（同一份引擎代码，已抽 20 个品逐一对齐）。 数据文件较大（原始 3.65 MB / gzip 约 1.28 MB），只有你点开这个区块时才开始下载，不拖慢首屏。

① 先建一个 Private 仓库，务必勾选 Add a README file（空仓库没法写入）。
② 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：Repository access 只选这个仓库，Permissions → Repository permissions → Contents: Read and write。
③ Token 只存在本机浏览器，不上传、不写进备份文件。建议有效期设 90 天后重新生成一次。

⚠️ 实测：国内很多网络会针对性阻断 *.supabase.co（DNS 能解析但 TLS 被重置），如果你的网络打不开就换 GitHub 后端。两个值在 Project Settings → API Keys，或项目页顶部 Connect 按钮里；它们本来就是公开值（千万别填 secret / service_role key）。

风险提示
  • 7 天 CD：市场/交易买入的饰品 7 天内不能再卖出，资金被锁死，务必留够现金。
  • 不要满仓、不要借钱、不要配资：CD 期内无法止损，杠杆会放大回撤。
  • 流动性：日成交量低的饰品，出货会被滑点吃掉利润，甚至砸盘卖不掉。
  • 计算器只是工具，不构成投资建议。
